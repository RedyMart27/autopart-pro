# Backend

API REST en Node.js + Express + MySQL organizada con MVC.

1. Copia `.env.example` a `.env` y configura la base de datos, un `JWT_SECRET` largo y `MP_ACCESS_TOKEN` con las credenciales de prueba si vas a probar Mercado Pago.
2. Ejecuta `npm install`.
3. Ejecuta `npm run dev` para desarrollo o `npm start` para iniciar.

La API local usa el puerto 3001. Rutas, acceso y cuerpos se describen en `../docs/API.md`. No subas `.env`.
