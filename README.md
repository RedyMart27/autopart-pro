# AutoPart Pro

Sistema web inteligente de inventario y ventas de repuestos automotrices.

## Objetivo

Desarrollar una aplicación web que optimice el control de existencias y facilite la venta técnica de repuestos automotrices.

## Funcionalidades principales

- Gestión de inventario y alertas de stock mínimo.
- Búsqueda avanzada por marca, modelo y año del vehículo.
- Gestión de ventas y pedidos.
- Integración de pasarela de pagos en entorno Sandbox.
- Documentación técnica y manual de despliegue.

## Estructura del proyecto

- `frontend/`: aplicación web.
- `backend/`: API REST y lógica de negocio.
- `database/`: scripts, migraciones y datos iniciales.
- `docs/`: documentación y diagramas.

## Equipo

Proyecto universitario desarrollado por un equipo de tres integrantes.
