# Frontend

Aplicación React + Vite para resumen, inventario, clientes, vehículos, ventas, historial y reportes.

1. Ejecuta `npm install`.
2. Ejecuta `npm run dev`.
3. Abre la dirección que imprime Vite, normalmente `http://localhost:5173`.

El proxy `/api` reenvía solicitudes a `http://localhost:3001`. El flujo local requiere que el backend y MySQL también estén iniciados. Ver `../README.md` para la instalación completa.
